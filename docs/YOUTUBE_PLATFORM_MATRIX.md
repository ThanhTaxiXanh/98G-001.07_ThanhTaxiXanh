# YouTube compatibility gate

| Surface | Trạng thái |
|---|---|
| Phone Settings | Chỉ cấu hình, không chạy player |
| Android Auto projection | Video/WebView tùy ý trong NavigationTemplate: BLOCKED_BY_PLATFORM |
| Android Auto Media audio | Chỉ audio hợp lệ qua host; NOT_IMPLEMENTED |
| Android Automotive OS | UNVERIFIED |
| Standalone Android head unit | OUT_OF_SCOPE / không tương đương AA |
